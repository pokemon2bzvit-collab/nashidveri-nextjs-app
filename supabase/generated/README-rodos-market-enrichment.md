# Rodos / Rodos Steel — пакет збагачення каталогу

Файл `rodos-market-enrichment.sql` додає або оновлює лише перевірені дані для 41 моделі Rodos та Rodos Steel:

- стислий український опис;
- 956 технічних характеристик;
- URL української картки Market Dveri як джерело фактів.

Пакет не змінює цін, фото, наявність, назву моделі, декори чи колекції.
До нього не ввійшли 308 моделей без однозначного збігу: їх треба звіряти окремо, щоб не підставити характеристики іншої двері.

## Як застосувати

1. Відкрийте Supabase → **SQL Editor** → **New query**.
2. Відкрийте `rodos-market-enrichment.sql`, скопіюйте весь текст і натисніть **Run**.
3. Очікуваний результат: `Success. No rows returned`.

`rodos-market-enrichment-data.json` і `rodos-market-match-report.json` — лише звіт та резерв для перевірки; виконувати їх не потрібно.
