# Наші двері — виконані роботи

Оновлено: 29 серпня 2026

## Проєкт

- Сайт магазину **«Наші двері»** у м. Ужгород.
- Технології: Next.js (App Router), TypeScript, Tailwind CSS, Lucide Icons, компоненти у стилі shadcn/ui.
- Деплой: Vercel.
- Каталог і медіа: Supabase (Postgres + Storage bucket `catalog-images`).

## Реалізовано

### Сайт і навігація

- Багатосторінкова структура: головна, каталог, міжкімнатні двері, вхідні двері, вікна, сторінки фабрик, контакти та сторінки окремих товарів.
- Адаптивний світлий дизайн із теплими деревними акцентами.
- Оновлені контактні дані: Ужгород, вул. Івана Чендея; телефони, пошта, Facebook та Instagram.
- Мобільна нижня панель для швидкого дзвінка та повідомлення.
- Форми консультації, заміру й зворотного зв’язку.

### Каталог товарів

- У каталозі **363 моделі** від фабрик Abwehr, Grand, Magda, Papa Carlo, Q Doors, Rodos, Rodos Steel, StilDoors, Страж і Термінус.
- Категорії, фабрики, колекції та фільтри працюють через параметри URL — ними зручно ділитися.
- На сторінці моделі є фото, характеристики, фабрика, колекція, товари з тієї ж колекції та CTA для консультації/заміру.
- Фото дверей у картках і на сторінках товарів показуються повністю без обрізання.
- Натискання на фото відкриває плавний повноекранний перегляд.

### Декори та конфігуратор

- У базі збережені тисячі варіантів кольорів, скла, кромок і покриттів.
- Для Papa Carlo налаштовані точні варіанти зображень: зміна кольору, скла або кромки змінює фото моделі, коли виробник надає точний рендер.
- Для частини Rodos додано варіанти зображень під конкретні конфігурації.
- Створено єдину панель **«Обрати декор»**:
  - на телефоні відкривається знизу;
  - на комп’ютері виїжджає справа;
  - показує тільки доступні параметри;
  - блокує несумісні комбінації, якщо вони відомі;
  - показує мініатюру обраної моделі;
  - оновлює фото, коли є точне зображення для вибраного декору;
  - чесно залишає базове фото, якщо виробник не має окремого рендера кольору.

### Виробники та медіа

- Додано логотипи виробників у каталозі та на сторінках товарів.
- **Abwehr:** усі 14 моделей мають додаткові офіційні ракурси у галереї.
- **Rodos Loft:** 18 моделей мають додаткові офіційні фото.
- Додаткові фото беруться напряму з офіційних джерел виробників, тому не навантажують Vercel.
- Для Cortes Dolce-3 доступна палітра з 18 RAL-кольорів; виробник не публікує окремий рендер дверей для кожного кольору.
- Для Grand Delux 14 BLK підтверджено 8 декорів: темно-сірий, дрімвуд сірий, клен білий, дрімвуд темний, світло-сірий, беж, сосна крем, ПВХ білий мат.

## Supabase

- Створені таблиці для товарів, додаткових медіа, опцій і точних варіантів зображень.
- Завантажено зображення товарів у public bucket `catalog-images`.
- Налаштовано публічне читання фото для сайту.
- Додані SQL-файли в папці `supabase/`, щоб усі зміни каталогу можна було відтворити.

## Що залишилося

1. Продовжити офіційні галереї для Rodos (Cortes, Siena) та інших фабрик лише там, де є точне зіставлення моделей.
2. Додати реальні текстури декорів Grand, якщо фабрика надасть PDF-палітру або окремі файли зразків.
3. За наявності офіційних рендерів — додати точну зміну фото для інших виробників.
4. Внести актуальні ціни та наявність, коли буде прайс від магазину/фабрик.
5. Фінальний етап: SEO (метадані, schema.org, sitemap, тексти категорій), аналітика та підсумкова перевірка мобільної версії.

## Як оновлюється сайт

1. У GitHub Desktop зробити Commit усіх потрібних змін.
2. Натиснути **Push origin**.
3. Vercel автоматично збере сайт з гілки `master` і опублікує зміни.
4. Після оновлень Supabase дані можуть з’являтися на сайті до 5 хвилин через кешування.

`tsconfig.tsbuildinfo` не потрібно додавати до комітів — він ігнорується Git.
