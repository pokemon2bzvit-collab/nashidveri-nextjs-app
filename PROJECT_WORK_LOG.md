# Наші двері — виконані роботи

Оновлено: 30 серпня 2026

## Проєкт

- Сайт магазину **«Наші двері»** у м. Ужгород.
- Технології: Next.js (App Router), TypeScript, Tailwind CSS, Lucide Icons, компоненти у стилі shadcn/ui.
- Деплой: Vercel.
- Каталог і медіа: Supabase (Postgres + Storage bucket `catalog-images`).

## Реалізовано

### Сайт і навігація

- Багатосторінкова структура: головна, каталог, міжкімнатні двері, вхідні двері, вікна, сторінки фабрик, контакти та сторінки окремих товарів.
- Адаптивний світлий дизайн із теплими деревними акцентами.
- Оновлені контактні дані: Ужгород, вул. Івана Чендея; телефони, пошта, Facebook та Instagram.
- Мобільна нижня панель для швидкого дзвінка та повідомлення.
- Форми консультації, заміру й зворотного зв’язку.

### Каталог товарів

- У каталозі **363 моделі** від фабрик Abwehr, Grand, Magda, Papa Carlo, Q Doors, Rodos, Rodos Steel, StilDoors, Страж і Термінус.
- Категорії, фабрики, колекції та фільтри працюють через параметри URL — ними зручно ділитися.
- На сторінці моделі є фото, характеристики, фабрика, колекція, товари з тієї ж колекції та CTA для консультації/заміру.
- Блок **«Технічні характеристики»** згорнутий за замовчуванням і плавно розкривається за натисканням — це зберігає компактний вигляд картки на телефоні.
- Фото дверей у картках і на сторінках товарів показуються повністю без обрізання.
- Натискання на фото відкриває плавний повноекранний перегляд.

### Декори та конфігуратор

- У базі збережені тисячі варіантів кольорів, скла, кромок і покриттів.
- Для Papa Carlo налаштовані точні варіанти зображень: зміна кольору, скла або кромки змінює фото моделі, коли виробник надає точний рендер.
- Для частини Rodos додано варіанти зображень під конкретні конфігурації.
- Створено єдину панель **«Обрати декор»**:
  - на телефоні відкривається знизу;
  - на комп’ютері виїжджає справа;
  - вибір у панелі застосовується лише після натискання кнопки **«Застосувати»**;
  - показує лише активні декори, для яких у базі є окреме підтверджене фото саме цієї моделі;
  - варіанти без окремого фото відображаються неактивними, щоб не вводити клієнта в оману;
  - показує мініатюру обраної моделі;
  - оновлює фото лише за точною прив’язкою «декор → фото моделі».

### Виробники та медіа

- Додано логотипи виробників у каталозі та на сторінках товарів.
- **Abwehr:** усі 14 моделей мають додаткові офіційні ракурси у галереї.
- **Rodos Loft:** 18 моделей мають додаткові офіційні фото.
- Додаткові фото беруться напряму з офіційних джерел виробників, тому не навантажують Vercel.
- Для Cortes Dolce-3 доступна палітра з 18 RAL-кольорів; виробник не публікує окремий рендер дверей для кожного кольору.
- Для Grand Delux 14 BLK підтверджено 8 декорів: темно-сірий, дрімвуд сірий, клен білий, дрімвуд темний, світло-сірий, беж, сосна крем, ПВХ білий мат.
- Для **Grand Delux 12** додано та перевірено повнорозмірні фото декорів «Дрімвуд темний» і «ПВХ білий мат». Декор «Клен білий» не активується, доки для нього не буде окремого коректного фото.

- Основне джерело для пакетного наповнення: **Market Dveri**. У картках товарів доступні назва, фото, опис, ціна, колекція та технічні характеристики.
- Посилання на каталоги Market Dveri:
  - [Rodos](https://market-dveri.ua/uk/rodos-m269/), [Papa Carlo](https://market-dveri.ua/uk/papa-karlo-m107/), [Abwehr](https://market-dveri.ua/uk/abwehr/), [Страж](https://market-dveri.ua/uk/straj-m43/);
  - [Rodos Steel](https://market-dveri.ua/uk/rodos-steel-m289/), [Magda](https://market-dveri.ua/uk/arma-m227/), [StilDoors](https://market-dveri.ua/uk/stildoors/), [Термінус](https://market-dveri.ua/uk/terminus-m34/).
- Для **Qdoors** використовуємо першоджерело — [офіційний каталог Qdoors](https://qdoors-dveri.com.ua/dveri/).
- Правило імпорту: додавати лише дані, які можна точно зіставити з нашою моделлю за фабрикою, назвою та колекцією. Не переносити ціну як постійну, якщо вона не узгоджена з магазином.
- Порядок пакетного наповнення: зіставлення моделі → фото → короткий і повний опис → технічні характеристики → варіанти декорів лише за наявності окремих фото.

### Характеристики моделей

- Створено окрему структуру для технічних характеристик, незалежну від опису й декорів.
- Базові підтверджені характеристики додано для **всіх 363 моделей**: категорія, доступні декори, покриття, скло, кромки та комплектації — якщо такі дані є в каталозі.
- У базі зараз **882 активні записи характеристик**.
- Для 6 моделей Abwehr (Limana, Melany, Mira, Rain, Riviera, Selena) додано перевірені параметри комплектацій: товщина полотна й короба, метал, МДФ-накладки, утеплення, ребра жорсткості, петлі, антизрізи та, де підтверджено, замки.
- Для характеристик вимкнено серверне кешування, тому зміни в Supabase стають доступними на сторінці моделі без очікування оновлення каталогу.

## Supabase

- Створені таблиці для товарів, додаткових медіа, опцій, точних варіантів зображень і технічних характеристик (`product_specs`).
- Завантажено зображення товарів у public bucket `catalog-images`.
- Налаштовано публічне читання фото для сайту.
- Налаштовано публічне читання характеристик: сайт має лише доступ на перегляд, без прав на редагування даних.
- Додані SQL-файли в папці `supabase/`, щоб усі зміни каталогу можна було відтворити, зокрема `product-specs-migration.sql`, `product-specs-seed-abwehr.sql` і `product-specs-catalog-baseline.sql`.

## Адмінка каталогу

- Додано закриту сторінку `/admin` для керування каталогом без SQL.
- Вхід виконується одноразовим magic-link на email адміністратора; доступ налаштовано для `pokemon2bzvit@gmail.com`.
- В адмінці можна редагувати ціну, опис, видимість товару та головне фото.
- Редактори характеристик, декорів і відповідностей «варіант → фото» зроблені у вигляді звичайних полів. JSON приховано в розділі «Розширений режим» для нестандартних випадків.
- Додано **«Бібліотеку джерел»**: Market Dveri, Abwehr, Grand, Papa Carlo, Qdoors і Страж. Вона відкриває каталоги в новій вкладці та пояснює безпечний порядок роботи.
- Для кожної моделі є окремий блок **«Перевірені джерела»**. Туди додаємо URL саме картки потрібної моделі, а не загальну сторінку фабрики — це унеможливлює плутанину зі схожими моделями.
- Додано редактори галереї, палітр та посилань на перевірені джерела.
- Фото можна додавати посиланням або завантажувати в bucket `catalog-images`.
- Для увімкнення адміністрування потрібно один раз виконати `supabase/admin-dashboard-security.sql` у Supabase SQL Editor. RLS-політики гарантують, що публічний сайт не отримує прав на редагування.

- Додано повне керування структурою каталогу: фабрики, колекції та товари-чернетки можна створювати, редагувати, приховувати й видаляти через адмінку.
- Перед видаленням фабрики або колекції адмінка перевіряє, чи є в ній товари. Це захищає каталог від випадкової втрати структури.
- Для керування структурою потрібно одноразово виконати файл supabase/catalog-structure-management.sql.

## Прийом заявок

- Для запуску потрібно одноразово виконати файл supabase/leads-management.sql.

## Як оновлюється сайт

1. У GitHub Desktop зробити Commit усіх потрібних змін.
2. Натиснути **Push origin**.
3. Vercel автоматично збере сайт з гілки `master` і опублікує зміни.
4. Опції та медіа можуть оновлюватися із короткою затримкою кешу; характеристики товару запитуються без кешування.

`tsconfig.tsbuildinfo` не потрібно додавати до комітів — він ігнорується Git.
