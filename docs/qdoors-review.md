# Звірка каталогу Qdoors

Зміна від 2026-09-05. У вкладці джерел адмінки сканер відкриває модель у модальному вікні. На ПК джерело й наш товар показані поруч; на мобільному — вкладки «У виробника» та «У нас».

- Пошук і вибір нашої моделі доступні у вікні. Приблизний збіг за назвою є лише підказкою; збережений зв’язок через product_sources підставляється автоматично.
- «Це наша модель» зберігає тільки зв’язок із джерелом.
- «Оновити вибрані дані» переносить позначені групи: головне фото, опис, характеристики, декор з фото. Головне фото за замовчуванням не вибране. Характеристики з однаковими назвами замінюються.
- «Додати нову модель» доступне без вибраного нашого товару. Призначення визначається з даних Qdoors або серії. Невідоме призначення потребує ручного додавання.
- «Наступна» зберігає список сканера та його позицію. Збереження не закриває вікно.
- Escape закриває вікно, крім часу збереження. Фото й обидві картки можна відкрити в окремій вкладці.

Записи виконуються через чинні Supabase RLS. SQL-міграція не потрібна. Оновлення кількох таблиць не є транзакцією: при помилці інтерфейс повідомляє про можливе часткове збереження. Нові товари створюються опублікованими після кнопки додавання, як у попередній версії імпортера.

Перевірка: TypeScript без помилок. Локальна Next.js production-збірка зупинилася на spawn EPERM у середовищі Windows; production-деплой ще не перевірено.
